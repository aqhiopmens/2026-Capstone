# B: 통제 수집 LOSO 평가 결과 (안건 12, 1단계 2026-11-09, 2단계 2026-11-10)

사전 고정 문서 [track_b_collect_prereg.md](track_b_collect_prereg.md)(개정 5f)대로 같은 서버·같은 클라이언트로 정상과 공격(로그인 무차별 대입)을 보낸 통제 수집 5,280연결을 서버 구성 단위로 평가했다. **서버 구성 3개·공격 1종의 탐색적 결과이며 새 환경·미지 공격 일반화의 근거가 아니다.** 모델 점수는 합산 macro-F1(3폴드 혼동행렬 합산 후 시드별 계산, 시드 평균)이며 CI는 시험 라운드 블록 부트스트랩(2,000회, 조건부)이다. 다중 비교 보정은 하지 않았고 구간이 0을 포함하는지로 유의성을 판정하지 않는다.

- 원본·평가 산출물 위치: Drive `2026-Capstone-data/collect_main/`(원본 13개 파일), `eval_2026-11-09_v1/`(1단계), `eval_2026-11-10_v1/`(2단계). 각 폴더에 SHA256SUMS가 있다.

## 2단계: 사전 등록 탐색 (run `2026-11-10_v1`, 코드 `5589f2c`, 한 축씩, 무지원 대비 paired 차이)

## 해석 한정과 미실행
- 이 결과는 "같은 로그인 공격이 새 TLS 서버 구성에서 얼마나 유지되고 소량 라벨이 얼마나 회복시키는가"에 대한 탐색이다. 미학습 공격 zero-shot 탐지 성공이 아니다. k=10에서 조기 탐지가 어려운 결과는 연결 하나의 초기 패킷에 로그인 실패 행동 외 구분 신호가 없게 설계했기 때문일 수 있다.
- **미실행**: 4.4 단계적 판정 정책(검증 폴드 설계·누적 FPR 목표를 시험과 분리해 먼저 고정해야 함). k=20·30 적응 조건도 사전 등록 범위 밖이라 돌리지 않았다.
- **이력**: 1단계·2단계 모두 구현 확인용 스모크(커밋 전)에서 점수를 먼저 보았고, 공식 실행은 깨끗한 커밋에서 같은 값으로 재현했다(변경 기록 참조).
- **독립 검증**: 1단계는 Codex가 Mac에서 72모델을 재학습해 라벨·행 키·SHA·선택 열·집계를 대조했고 일치했다(`p_attack`은 환경 차이로 최대 0.03 차이, 라벨은 동일). 2단계 재계산은 대기 중이다.
- **환경**: Windows 11, Python 3.14.3, sklearn 1.8.0, numpy 2.4.3, pandas 3.0.1, LightGBM 4.6.0(Mac 재계산은 sklearn 1.6.1/numpy 2.0.2/pandas 2.2.2). 시드 0·1·2는 모델 난수만 바꾸며 독립 표본이 아니다.
