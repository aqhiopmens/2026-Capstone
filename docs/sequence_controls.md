# 시퀀스 순서 섞기와 학습 패턴 조회 기준선

원본 재전처리 데이터와 [특징군 비교](feature_group_experiment.md)의 외부 분할 6개를 그대로 사용한다. 이 단계는 RF·LightGBM의 위치 정보 대조와 13종 해시 조회 기준선이다. CNN·LSTM, 미확인 거절 문턱, 최종 Colab 수치는 포함하지 않는다.

## 순서 섞기

- 원본 92,034행에서 0은 모두 뒤쪽에만 있으며 전부 0인 행은 없음을 확인했다. 패딩 위치·유효 패킷 수는 유지하고 각 행의 **0이 아닌 부호 있는 길이 값만 독립적으로 순열화**한다. 길이 값의 집합·부호·0 위치는 그대로다
- 각 행의 원본 source_row와 섞기 시드로 난수 생성기를 만든다. 행 정렬이나 청크 크기가 달라도 같은 행·시드는 같은 결과다. 모든 행에 같은 열 순열을 적용하는 방식은 순서 파괴가 아니므로 쓰지 않는다
- 분할·그룹 ID는 **섞기 전 원본 패턴**을 유지한다. 섞은 패턴으로 재분할하지 않는다. 같은 시드의 섞인 입력을 두 모델·두 분할에 재사용한다
- 분할 2 × 모델 2 × 시드 3 = **12회 재학습**. 외부 train 전체, RF·LightGBM 100개 트리·balanced·worker 2개, 검증 분리·튜닝·스케일링 없음
- 원순서의 시퀀스 단독 12조건은 완료된 기존 48회 배치에서 가져온다. 같은 machine·입력 파일·코드·모델 파라미터·라이브러리 버전과 validation=0을 검사하고 조건별 점수 차이(섞기−원순서)를 기록한다
- 분할·모델·섞기 시드는 0/1/2로 함께 바뀐다. 분할·학습·섞기 변동을 분리하지 않으며, 한 분할에 대한 섞기 반복 신뢰구간이 아니다

이 대조는 트리 모델의 패킷 위치 정보 의존도를 본다. 섞기는 행간 동일 패턴의 반복 관계도 바꾸며, 패킷 수·길이 분포·방향 수는 보존한다. 점수 차이를 순수한 시간 순서의 인과 효과로 해석하거나 CNN/LSTM 필요성을 확정하지 않는다. 추후 순서 모델 비교가 필요하다.

## 해시 룰

- 원본 30개 시퀀스의 검증된 SHA-256 ID를 키로 사용한다. **train 행의 라벨만** 세어 패턴별 최빈 클래스를 저장한다. 충돌 라벨의 표 수가 같으면 문자열순으로 선택한다
- 시험에서 본 적 있는 패턴은 저장 라벨을 조회하고, 처음 보는 패턴은 **train 전체 최빈 클래스**로 예측한다(동률은 문자열순). 처음 보는 패턴을 임의로 악성·미확인이라고 판정하지 않는다
- 알려진 13종 전체 시험 행에 대해 macro-F1·정확도·13×13 혼동 행렬을 계산한다. 조회 성공 행만 골라 전체 성능으로 보고하지 않는다. 조회율·성공 행 정확도·클래스별 조회율을 별도로 저장한다. 조회 성공 0행이면 성공 행 정확도는 비워 둔다
- 분할 2 × 시드 3 = **6회**. 랜덤 모델은 없으며 시드는 외부 분할만 바꾼다. 그룹 분할에서는 학습·시험 원본 패턴이 겹치지 않아 조회율 0이 예상되며, 전체 점수는 최빈 클래스 fallback의 성능이다
- unknown 예측도 DATA_DIR에 저장하지만 known 지표에서 제외한다. 이 조회 규칙은 미확인 탐지기가 아니다. 전체 데이터의 패턴-라벨 사전을 미리 만드는 oracle을 사용하지 않는다

## 실행·산출물

```sh
# DATA_DIR과 MACHINE을 먼저 설정한다.
python -m src.track_a.sequence_controls \
  --run-id sequence_controls_2026-10-29_mac \
  --baseline-run-id feature_group_2026-10-29_mac --workers 2
```

Colab은 workflow의 CPU 런타임·고정 버전 확인 후, 같은 환경에서 완료한 원순서 48회 배치의 ID를 baseline-run-id로 전달한다. 새 run-id를 사용하며 맥 기준선과 Colab 결과를 직접 짝지어 비교하지 않는다.

Git의 batch 디렉터리에는 18회 metrics.csv·confusion.csv(3,042칸), 6조건 summary.csv, 12조건 paired.csv, 해시 클래스별 조회율 78행 hash_coverage.csv, manifest.json을 남긴다. 개별 디렉터리는 공통 API의 metrics·confusion·metadata를 보존한다. 행별 예측·최종 배정은 DATA_DIR/predictions 아래에만 둔다. 해시 예측의 lookup_hit은 조회 여부이며 확률이 아니므로 max_probability를 만들지 않는다.

입력·기준선·실행 코드의 SHA-256, 시작 Git 커밋·dirty, 각 모델의 설정·버전을 기록한다. 기존 run-id는 덮어쓰지 않고 실패 시 complete=false로 남긴다. 18조건과 12개 짝 비교가 완료되고 입력·코드가 불변일 때만 complete=true다. 맥 수치는 예비이며 Colab 최종 수치는 별도 실행한다.

## 검사

`python -m unittest discover -s tests`: 34개 통과. 새 검사에는 값·부호·패딩 보존, 행 ID별 재현, 내부 0/결측 거부, train 라벨만 조회, 시험·unknown 라벨 변경 시 예측 불변, 그룹 미조회 전체 점수와 fallback, 다른 machine/불완전 원순서 기준선 거부가 포함된다.

## 10/29 맥 결과 — 예비

`sequence_controls_2026-10-29_mac` 18/18회 완료, complete=true. 실행 커밋 `a8bd3be`, 시작 Git 상태 clean, 종료 시 입력·원순서 기준선·실행 코드 해시 불변. 원순서 비교는 같은 맥의 `feature_group_2026-10-29_mac` 시퀀스 단독 12조건을 사용했다. 아래 점수는 macro-F1이며 섞기 점수의 ±는 시드 3개의 표본 표준편차다.

| 모델 | 분할 | 원순서 평균 | 섞기 평균 ± 편차 | 평균 차이(섞기−원순서) |
|---|---|---|---|---|
| RF | 무작위 | 0.9139 | 0.7860 ± 0.0057 | −0.1279 |
| RF | 원본 패턴 그룹 | 0.8803 | 0.7840 ± 0.0431 | −0.0963 |
| LightGBM | 무작위 | 0.9176 | 0.8696 ± 0.0020 | −0.0480 |
| LightGBM | 원본 패턴 그룹 | 0.8828 | 0.8032 ± 0.0619 | −0.0796 |

현재 트리 모델에서 패킷 위치 정보를 없애면 평균 점수가 낮아진다. 다만 행별 섞기는 반복 관계도 바꾸며, 분할·모델·섞기 시드가 함께 바뀌므로 이를 순수 순서 효과나 순서 모델 필요성의 확정 근거로 삼지 않는다.

| 해시 조회 | macro-F1 평균 ± 편차 | 정확도 평균 | 시험 조회율 |
|---|---|---|---|
| 무작위 | 0.7625 ± 0.0026 | 0.8716 | 시드별 70.03~70.33% |
| 원본 패턴 그룹: 미조회 fallback | 0.0528 ± 0.0000 | 0.5228 | 모두 0% |

무작위의 조회 성공 행 정확도는 94.45~94.53%지만 이는 전체 성능이 아니다. 그룹은 모두 미조회로 train 최빈 라벨 benign을 예측한 결과다. 정상·공격 패턴이 전체 데이터에서 겹치지 않는다는 사실만으로 train 조회 규칙의 새 패턴 일반화가 보장되지는 않는다.

발표 본문에서는 “무작위는 학습 패턴을 조회할 수 있지만 그룹은 조회율 0%여서 조회를 통한 분류가 불가능하다”를 중심으로 설명한다. 그룹의 0.0528은 패턴 조회 능력의 비교 점수가 아니라 fallback 동작의 수치다. 재현을 위해 CSV와 위 표에는 보존하되, 다른 모델과 함께 표시할 때는 미조회 fallback임을 반드시 병기한다.

수치 원본은 `outputs/results/sequence_controls_2026-10-29_mac/`의 metrics·summary·paired·confusion·hash_coverage·manifest에 있다. 저장된 18개 예측·배정을 모두 읽어 원본 배정·실제 라벨을 대조하고, 혼동 행렬에서 점수와 6조건 집계를 별도 수식으로 재계산했다. 해시 예측은 train만으로 만든 별도 crosstab 사전 및 fallback과 일치했고 78개 클래스 조회율·12개 원순서 차이도 일치했다. 시드 3개의 전체 92,034행에서 섞기 후 값 집합·부호·0 위치 보존도 검사했다.

## 변동과 변환 후 겹침의 추가 점검

그룹 시드 1에서 burpsuite 시험 959행의 recall이 RF 0.0042·LightGBM 0.0073으로 낮아졌다(원순서는 둘 다 1.0). 시드 0·2의 섞기 recall은 0.9990~1.0이다. 이 조건을 제외하거나 시드를 다시 고르지 않았으며, 큰 편차와 함께 보고한다. 정확한 원인은 아직 확정하지 않았다. 순서를 무시한 값 집합의 학습 조회율은 burpsuite 그룹 시험에서 세 시드 모두 0%로, 시드 1만의 차이를 설명하지는 않는다.

평균과 함께 제시할 그룹 분할 시드별 macro-F1은 다음과 같다. 원순서와 섞기 모두 동일한 해당 시드의 외부 배정을 사용한다.

| 모델 | 시드 | 원순서 | 섞기 | 차이 |
|---|---|---|---|---|
| RF | 0 | 0.8743 | 0.8124 | −0.0620 |
| RF | 1 | 0.8832 | 0.7344 | −0.1487 |
| RF | 2 | 0.8835 | 0.8051 | −0.0784 |
| LightGBM | 0 | 0.8928 | 0.8373 | −0.0555 |
| LightGBM | 1 | 0.8744 | 0.7317 | −0.1428 |
| LightGBM | 2 | 0.8811 | 0.8405 | −0.0406 |

Claude의 가설을 원본 재전처리 저장본으로 대조했다. burpsuite는 전체 16패턴 중 학습 12패턴·3,839행, 시험 4패턴·959행으로 모든 시드의 건수는 같다. 다음 평균은 **시퀀스의 비영 칸 수(관측 페이로드 패킷 개수)**이며 바이트 길이 평균이 아니다.

| 시드 | 학습 비영 칸 수 평균 | 시험 비영 칸 수 평균 | 시험의 주요 구성 |
|---|---|---|---|
| 0 | 7.0414 | 5.9990 | 6패킷 955행 |
| 1 | 6.2959 | 8.9833 | 9패킷 954행 |
| 2 | 7.0425 | 5.9948 | 6패킷 954행 |

시드 1의 burpsuite 학습에는 9패킷 행이 없고 시험에는 954행이 있다. 다만 학습에 15패킷 행도 1행 있으므로 “시험이 학습의 최대 길이를 넘었다”고 말하지 않는다. 패턴 구성 이동과 섞기의 상호작용이 하락에 기여했을 가능성은 있지만, 분할·모델·섞기 시드를 따로 고정한 실험을 하지 않아 원인으로 확정하지 않는다.

원본 그룹 ID는 학습·시험에서 분리되어 있지만 **섞은 뒤 우연히 같은 입력이 새로 생길 수 있다**. 그룹 시드 0은 변환된 학습·시험 입력 겹침 0개, 시드 1·2는 각 1개 패턴·시험 1행의 겹침을 확인했다. 따라서 섞은 입력까지 완전히 격리됐다고 주장하지 않는다. 무작위의 변환 후 시험 조회 행은 3,455/3,517/3,478행이다. 원본 분할을 유지한 대조의 한계로 기록하며, 이 관측 후 시험 행을 지우거나 재분할하지 않는다.

## Claude 교차 검토 (10/29)

Claude는 김강민 요청으로 Windows 테스트 34개 통과, 원본 3시드 섞기의 패딩·값 집합 보존 및 행 역순 재현, 6조건 해시 점수 일치를 보고했다. 섞기 모델 일부 8조건을 재실행해 LightGBM은 소수 넷째 자리까지 일치하고 RF는 최대 0.006 차이를 보고했다. 부분 조건의 교차 환경 검증이며 전체 조건의 동일성을 뜻하지 않는다. RF 차이의 원인은 확정하지 않았다.

그룹 시드 1의 burpsuite recall RF 0.0042·LightGBM 0.0073도 Windows에서 재현됐다고 보고했다. Mac에만 나타난 현상이라는 근거는 없다. Claude의 패턴 구성 가설을 위 표로 대조했고 시드별 점수·fallback 설명을 보완했다. Claude가 이번에 직접 확인하지 못한 범위는 Mac의 행별 예측 18개, 추가 분석 산출물, 변환 후 시험 1행 겹침이다. 검토 의견은 “병합 가능, 확인할 점 3개”이며 [Slack 원문](https://the2026-capstone.slack.com/archives/C0CCD9LQPBQ/p1793269149225539)에 있다.

맥 결과는 예비이며 Colab 최종 재실행은 아직 남아 있다. 교차 검토와 문서 보완 뒤 서은빈이 이 채팅에서 PR #14 병합 및 완료 보고를 별도 승인했다. CNN·LSTM과 미확인 위협 판정은 이 PR에서 착수하지 않았다.
