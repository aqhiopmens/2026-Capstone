## 과제 개요

◦ 과제 선정 배경
- 인터넷 트래픽의 약 96%가 TLS/QUIC으로 암호화됨에 따라 기존 페이로드 기반 시그니처 탐지 방식이 한계에 도달함
- 포트 기반 탐지 역시 동적 포트 할당과 VPN 우회로 신뢰성이 저하되는 상황
- DoS, DDoS, 봇넷 등 다양한 공격 트래픽이 암호화된 채로 유통되어 복호화 없이 탐지 가능한 새로운 방법론이 필요한 상황

◦ 과제의 필요성
- 기존 공개 데이터셋에는 레이블 오류, 태스크 무관 배경 트래픽, IP·포트 등 강력한 식별자(Strong Identification Information)가 포함되어 딥러닝 모델이 실제 공격 패턴이 아닌 식별자를 학습하는 Shortcut Learning 문제 발생
- 공격 트래픽 데이터셋의 노이즈를 체계적으로 정의·제거하고 최적의 특징 추출 설계를 통해 실제 환경에서도 일반화된 딥러닝 기반 탐지 시스템 구축 필요
- 패킷 내용 복호화 없이 겉면 패턴(패킷 크기·전송 간격·SYN/ACK 비율·TLS 핸드셰이크 타이밍)만으로 공격 유형을 분류하는 딥러닝 방법론 연구 필요

## 과제 내용

◦ 과제 구성
- 1단계: 트래픽 데이터셋 수집 및 분석 — CIC-IDS2017, Malicious_TLS, USTC-TFC2016 데이터셋 수집·구조 파악
- 2단계: 노이즈 제거 및 특징 추출 설계 — 레이블 노이즈·배경 트래픽·SII(IP/Port) 제거, 상관관계 분석 및 RF 중요도 기반 최적 특징 선택
- 3단계: 딥러닝 모델 구현 및 성능 검증 (캡디 II 진행 예정) — CNN/LSTM 기반 분류 모델 구현, XAI 기반 특징 중요도 분석

◦ 과제 주요 특징
- Strong Identification Information(IP·Port·도메인) 제거를 통한 Shortcut Learning 방지 및 모델 일반화 성능 향상
- 레이블 노이즈, 태스크 무관 트래픽, 타겟 노이즈, 써드파티 노이즈 4가지 유형으로 체계적 노이즈 정의 및 제거 파이프라인 구현
- 상관관계 분석 + RF 중요도 분석을 통한 최적 특징 선택:
  CIC-IDS2017: 68→32개로 절감
  Malicious_TLS: 117→68개로 절감
- Baseline RF 모델 실험 결과
  특징 수 절감 후에도 Accuracy 유지 (99.86%/99.11%)
  학습 시간 최대 32% 단축으로 최적 특징 추출 설계 효과 검증
- 통계적 특징(플로우 기반) 및 바이트 시퀀스(CNN 입력 28×28) 두 가지 특징 추출 방향 병행 설계로 이후 성능 비교 실험 기반 마련

## 결과물의 활용방안 및 기대효과

1. 암호화 환경에서도 내용 복호화 없이 공격 탐지 가능한 파이프라인 구축 — 실제 네트워크 보안 장비 및 IDS/IPS 시스템에 적용 가능한 기술 기반 마련
2. 공개 데이터셋의 노이즈 문제를 체계적으로 분석·개선하는 방법론 제시 — 관련 분야 연구 논문 발표 가능성
3. Strong ID 제거 기반 일반화 모델 구현 — 특정 IP·포트에 의존하지 않아 다양한 네트워크 환경에 범용 적용 가능
4. XAI 기반 특징 중요도 시각화 (캡디 II 구현 예정) — 보안 전문가가 탐지 근거를 확인할 수 있어 실무 환경 도입 신뢰성 확보
5. 참여기업 ㈜하잎아이피와의 협업을 통해 실무 관점 기술 자문 반영 — 산학협력 연구 성과물로 활용 가능
