# 10/27 특징군 예비 비교

캡디1 정제본으로 발표에 넣을 첫 비교표를 만든다. **분할 전에 전체 데이터로 정제 기준을 산출한 누수가 남아 있어 정식 기준선이나 일반화 입증으로 사용하지 않는다.** 원본부터 다시 만드는 정식 실험은 별도다.

## 조건

- 입력: `$DATA_DIR/processed/malicious_tls_cleaned.csv`, 90,925행, 117개 특징과 Label. 추가 정제·스케일링·특징 선택 없음
- 클래스: 설계상의 패턴 부족 5종 제외, 18종 중 미확인 위협 보류 후보 5종 격리. **알려진 13종 64,850행**의 다중 분류. 보류 5종의 최종 선정 검증이나 OOD 평가는 수행하지 않음
- 제외: Shifu.A, Banker, Drixed, Vawtrak.C, golistmero(원본 라벨 철자)
- 보류 후보: nessus, arachni, Totbrick, Tiggre, TrickBotCC(원본 라벨 철자)
- 특징: 전체 117 / TLS 지문 9 / IP·payload 통계 78 / 방향 부호가 있는 패킷 길이 시퀀스 30
- 모델: RF 100 trees, class_weight=balanced. LightGBM 100 estimators, class_weight=balanced, 나머지는 설치 버전 기본값. RF·LightGBM 모두 CPU 작업자 4개로 맥 8GB 부담 제한
- 시드: 0, 1, 2. **분할과 모델 시드가 함께 바뀌므로 표준편차에는 두 변동이 포함된다.** 평균±표본표준편차(ddof=1)
- 기계: eunbin-mac. 최종 보고서 수치는 Colab에서 별도 재실행

## 분할

무작위 분할은 클래스 층화 80/20이다. 그룹 분할은 원래 시퀀스 30개가 완전히 같은 행들을 한 그룹으로 묶으며 클래스가 달라도 같은 그룹이다.

초기 검증에서 StratifiedGroupKFold(5, shuffle=True)의 첫 폴드에 일부 클래스가 없거나 30행 미만인 문제가 발견되어 모델 학습 전에 중단했다. 최종 규칙은 다음과 같다.

1. 그룹 ID를 시드별 순열로 치환해 동일 크기 그룹의 배정 순서에 변동을 준다.
2. StratifiedGroupKFold(5, shuffle=False)로 큰 그룹부터 배정한다.
3. 모든 클래스의 학습·시험이 각각 30행 이상인 폴드만 후보로 삼는다.
4. 전체 시험 비율이 20%에 가장 가까운 폴드를 선택한다(동률은 폴드 번호순). 모델 점수는 사용하지 않는다.

세 시드 모두 선택된 폴드는 4번이며 학습 52,040행·시험 12,810행(시험 19.75%)이다. 무작위 분할은 학습 51,880행·시험 12,970행이다. 큰 패턴을 나눌 수 없어서 클래스별 비율이 정확히 80/20이 되지는 않는다. 세 시드가 완전히 독립적인 시험 표본을 뜻하지 않으며 신뢰구간으로 해석하지 않는다.

## 재실행과 산출물

저장소 루트에서 다음을 실행한다. DATA_DIR이 필요하다.

```sh
uv run python src/track_a/feature_group_preview.py
uv run python src/track_a/feature_group_preview.py --model lgbm
```

`outputs/results/feature_group_preview_2026-10-27_{rf,lgbm}*`:

- `.csv`: 개별 실행 수치(모델당 24행), workflow.md의 공통 컬럼 포함
- `_summary.csv`: 특징군·분할별 평균과 표준편차
- `_class_counts.csv`: 클래스별 학습·시험 행 수·패턴 수와 겹침 검사
- `_confusion.csv`: 각 실행의 혼동행렬(실제 라벨·예측 라벨·건수)
- `_metadata.json`: 원본 체크섬, 사용 클래스, 제외·보류 후보, 분할 규칙

원본 행별 분할 배정은 데이터에 해당하므로 git에 넣지 않고 `$DATA_DIR/processed/preview_2026-10-27/`에 저장한다. 같은 입력으로 두 모델의 분할이 같은지 확인한다.

학습 전에 행 겹침, 그룹 겹침, 클래스 존재, 최소 30행, 보류 클래스 격리를 검사한다. 완료 후 24회 누락 여부와 혼동행렬 합계를 검사한다. macro-F1은 알려진 13종 전체를 고정 분모로 계산한다.
