# 암호화된 악성 트래픽 조기 탐지 및 분류 시스템

고려대학교 세종캠퍼스 캡스톤디자인 II (2026-2) · 팀 넷워처(김강민, 서은빈) · 지도교수 김명섭 · 참여기업 ㈜하잎아이피

복호화 없이 암호화된 트래픽의 초기 패킷만으로 악성 여부를 판별하고 공격 유형을 분류한다. 판정 근거가 IP·포트 같은 환경 식별자가 아니라 통신 행위에서 나왔는지를, 시간이 지난 데이터와 처음 보는 악성코드로 검증한다.
